# Duck Catcher — Duck × My × Duck

Расширение для браузера (Chrome / Edge / Brave / Yandex), которое автоматически ищет утку нужной редкости в чате Duck × My × Duck в Telegram Web и переходит по ссылке на неё. Дополнительно умеет собирать локальную статистику уловов и (по желанию) делиться анонимными данными о рынке.

Сайт с рынком в реальном времени: [myduckstats.vercel.app](https://myduckstats.vercel.app)

> ⚠️ Проект автоматизирует часть игрового процесса в стороннем Telegram-приложении. Используйте на свой риск — это может противоречить правилам конкретной игры или Telegram.

## Возможности

- **Умный отлов** — фильтр по редкости (Common → Secret) и уровню утки, с возможностью выбрать несколько целевых редкостей сразу
- **DRY-RUN режим** — только наблюдение и логирование, без реальных кликов, чтобы проверить настройки перед боевым запуском
- **Фильтры** — «только новые ссылки», «не ловить повторно одного партнёра»
- **Локальный дашборд** — история поимок, графики по редкости и активности по дням, экспорт в JSON/CSV
- **Market Monitor** (опционально) — считает состояние рынка (цены corn/stars, тип рынка normal/hot/crazy) и с явного согласия пользователя отправляет анонимный снапшот в общую статистику на DuckStats
- **Мультиязычный интерфейс** (i18n)
- **Проверка обновлений** — расширение сравнивает свою версию с API и показывает уведомление, если доступна новая версия

## Установка

Расширение пока не опубликовано в Chrome Web Store, ставится вручную — занимает пару минут:

1. **Скачайте архив**: зелёная кнопка `Code` → `Download ZIP` на странице репозитория
2. **Распакуйте ZIP** в постоянную папку (не удаляйте и не перемещайте её потом — иначе браузер потеряет расширение)
3. **Откройте страницу расширений**: `chrome://extensions` (Chrome), `edge://extensions` (Edge), `browser://extensions` (Yandex) или `brave://extensions` (Brave)
4. **Включите «Режим разработчика»** (переключатель в правом верхнем углу)
5. **Нажмите «Загрузить распакованное расширение»** и выберите папку из шага 2
6. **Готово** — закрепите иконку через значок пазла

Подробная инструкция со скриншотами и обновлениями: [myduckstats.vercel.app](https://myduckstats.vercel.app/#install)

Поскольку расширение не в Web Store, оно не обновляется автоматически — при выходе новой версии на иконке появляется badge `!`, а в дашборде отображается уведомление со ссылкой на скачивание.

## Как это устроено

| Файл | Роль |
|------|------|
| `content.js`, `shared.js` | Работают на web.telegram.org: парсят сообщения чата, ищут ссылки на уток нужной редкости |
| `miniapp-closer.js` | Служебные действия внутри мини-аппа (закрытие диалогов и т.п.) |
| `network-sniffer.js` | Инжектится в основной JS-контекст мини-аппа, читает данные напрямую из сетевых ответов приложения (без парсинга DOM) |
| `sniffer-relay.js` | Передаёт данные из основного контекста страницы обратно в расширение |
| `market-monitor.js` | Считает рыночные показатели и, при включённой настройке, отправляет анонимный снапшот на бэкенд DuckStats |
| `offscreen.js` / `offscreen.html` | Фоновые задачи, которым нужен DOM — сервис-воркер MV3 его не имеет |
| `background.js` | Service worker: уведомления, алармы, скачивания, проверка обновлений |
| `dashboard.html` | Локальная панель статистики и истории |
| `popup.html` / `popup.js` | Быстрые настройки и запуск/остановка лова |
| `options.html` / `options.js` | Полная конфигурация |

## Приватность

Передача данных о рынке **выключена по умолчанию** и включается пользователем вручную в настройках. Что уходит на сервер при включении:

- случайный `installId` (UUID, не привязан к Telegram-аккаунту)
- тип рынка, средние/мин/макс цены
- счётчики продаж и находок

Telegram ID, ник и содержимое сообщений на сервер не передаются никогда. Подробности — в разделе «Приватность» на [сайте](https://myduckstats.vercel.app/#trust).
